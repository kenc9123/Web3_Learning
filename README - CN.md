记录我从零开始学习 Web3 前端开发的过程，包括代码练习和学习笔记。

## 学习路线

> 第一阶段：HTML + CSS + JavaScript 基础

> 第二阶段：React 框架 + Web3 连接

> 第三阶段：Solidity 智能合约

> 第四阶段：项目实战
